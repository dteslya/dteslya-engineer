## Overview

Personal blog (https://dteslya.engineer) built with [Zensical](https://zensical.org) (the successor to Material for MkDocs, `classic` theme variant) and hosted on Netlify. There is no application code or test suite — the repo is Markdown content plus `zensical.toml`.

## Commands

```bash
pip install -r requirements.txt   # Python >= 3.11 (runtime.txt pins Netlify's version)
zensical serve                    # local preview at http://localhost:8000
zensical build --strict           # build into site/, failing on warnings
```

## Deployment

Netlify runs `pip install -r requirements.txt && zensical build` (see `netlify.toml`) and publishes `site/`. `site/` is build output and is git-ignored — don't commit it. Pull requests get free Netlify Deploy Previews.

## Configuration notes

- All config lives in `zensical.toml` under `[project]` (there is no `mkdocs.yml`). Zensical errors on unknown options for supported plugins and silently ignores unsupported plugins, so check https://zensical.org/compatibility/plugins/ before adding one.
- `git-committers` and `git-revision-date-localized` are not supported by Zensical yet, which is why pages show no "last updated" dates.
- Emoji extension uses `zensical.extensions.emoji.*`, not `material.extensions.emoji.*`.

## Content structure

- `docs/blog/posts/*.md` — blog posts (blog plugin; `blog_dir = "blog"`, archive on, author pages off). Images live in `docs/blog/posts/images/`.
- `docs/network-automation-101/` — a multi-page guide whose navigation is listed explicitly in `nav` in `zensical.toml`. New pages there must be added to `nav`.
- `docs/asciinema/` — `.cast` recordings, played via the bundled `asciinema-player` JS/CSS (`extra_javascript`/`extra_css`).
- `overrides/partials/comments.html` — Giscus comments, rendered only on pages with `comments: true` in front matter. Overrides are rendered with MiniJinja, so they can't call arbitrary Python.

### Blog post conventions

Front matter used by existing posts:

```yaml
---
title: "..."
description: "..."
categories:
- Tutorial
tags:
- docker
date: 2025-06-06
authors:
  - dteslya        # defined in docs/blog/.authors.yml
draft: false
comments: true
---
```

Posts then repeat the title as an `# H1`, show a cover `<figure markdown>` with a `<figcaption>` crediting the photo, and use `<!-- more -->` to mark the excerpt cutoff. Newer posts use a `YYYY-MM-slug.md` filename.

### URLs and redirects

Blog post URLs are generated by the blog plugin (date-based), not from file paths. When renaming or moving a page, add an entry to `[project.plugins.redirects.redirect_maps]` in `zensical.toml` so old links keep working.
